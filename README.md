# 🏓 Modern Neon Pong

Implementasi modern dari game klasik Pong dengan visual estetika **Cyberpunk/Neon**, efek partikel, dan gameplay yang telah dipoles. Proyek ini dibangun menggunakan **HTML5 Canvas**, **CSS3**, dan **Vanilla JavaScript** dengan arsitektur berbasis objek.

## ✨ Fitur Modern

- **Visual Neon Estetik**: Glow effects, gradien dinamis, dan palet warna cyberpunk.
- **Efek Partikel & Trail**: Jejak visual pada bola dan percikan partikel saat terjadi tabrakan (paddle/dinding).
- **Sistem State Game**: Layar Start, Pause, dan Game Over yang terintegrasi.
- **Gameplay Dinamis**: Kecepatan bola meningkat secara bertahap (Dynamic Difficulty) dan efek *Screen Shake* pada benturan keras.
- **AI Pintar**: Lawan AI yang memiliki tingkat kesulitan yang seimbang (tidak terlalu kaku).
- **Kontrol Responsif**: Mendukung input Mouse dan Keyboard (W/S atau Arrow Keys).
- **Arsitektur Kode Bersih**: Ditulis ulang menggunakan OOP (Object-Oriented Programming) untuk kemudahan pengembangan lebih lanjut.

## 🚀 Cara Menjalankan

1. **Clone** repository ini:
   ```bash
   git clone https://github.com/username/modern-pong.git
   ```
2. **Buka** file `index.html` langsung di browser Anda, atau gunakan extension seperti *Live Server* di VS Code untuk pengalaman terbaik.

## 🎮 Cara Bermain

- **Mouse**: Gerakkan kursor ke atas dan ke bawah untuk mengontrol paddle.
- **Keyboard**: Gunakan tombol `W`/`S` atau `Panah Atas`/`Bawah`.
- **Space**: Jeda (Pause) atau mulai ulang game.

## 🛠️ Struktur Proyek

- `index.html` - Struktur utama dan overlay UI.
- `style.css` - Styling neon, animasi, dan layout responsif.
- `game.js` - Logika inti game, mesin fisika, dan sistem render.
